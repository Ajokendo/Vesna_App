# Салон — онлайн-запись и CRM

Универсальное приложение для салонов красоты: онлайн-запись клиентов, журнал администратора, мастера и их графики.
Всё, что относится к салону (название, логотип, услуги, цены, мастера, графики), хранится в базе, а не в коде.
Первый салон — **«Весна»**, Бишкек.

## Что уже работает (этап 1)

- **Онлайн-запись** (`/vesna/book`): для себя или ребёнка → зал → длина волос → услуга и доп. опции → мастер → неделя и время → контакты.
  - цена по длине волос, «от–до» (тотал блонд), детская цена по возрасту ребёнка;
  - «снятие нашей работы бесплатно при повторном маникюре» — сервер сам проверяет историю визитов;
  - сложное окрашивание и тотал блонд — только у мастеров, которым это разрешено;
  - свободное время считается по графику конкретного мастера (дни недели или «6 через 1»), с шагом 5 минут:
    окно открывается сразу после предыдущей записи, поэтому короткие услуги идут подряд;
  - запись на 30 дней вперёд, не позже чем за час; две записи на одно время невозможны (блокировка в транзакции).
- **Журнал администратора** (`/vesna/admin`, вход по PIN): день по колонкам мастеров, вкладки «Парикмахеры / Ногтевой сервис / Брови и шугаринг», запись по телефону и «без записи».
- **Выдержка краски**: окрашивание делится на нанесение, выдержку и смывку; в выдержку мастер свободен — к нему можно записать другого клиента (и онлайн, и в журнале).
- **Касса и баллы** (в журнале — нажать на запись): цена, сколько баллов списать (можно часть), способ оплаты. Автоматически: списание баллов,
  начисление 5% с суммы, оплаченной деньгами, доля мастера 50% с той же суммы (у хозяйки-мастера комиссии нет). Внизу журнала — «Касса за день».
  Баллы детей копятся на счёте родителя; история баллов — таблица `points_ledger`; ошибочную оплату можно отменить.
- **Кабинет мастера** (`/vesna/master`, свой PIN): ближайшие 7 дней, записи с услугами из прайса и выдержкой краски, заработок по каждому клиенту
  с пояснением, если клиент платил баллами, итоги за день и месяц. PIN выдаёт администратор: журнал → «Мастера и PIN» (хранится хешем, 5 ошибок — блок на 15 минут).
- **Изменения графика** (журнал, шапка колонки мастера): «Не выйдет…» — на день, несколько дней или часть дня; «Выйдет в выходной…» — подмена
  или обмен выходными. Онлайн-запись сразу подстраивается. Уже записанные клиенты появляются списком «Нужно решить»: передать свободному мастеру,
  написать в WhatsApp (готовый текст) или отменить запись.
- **Время записи** (журнал → нажать на запись): мастер закончит раньше или задержится — меняем время окончания (−15/−5/+5/+15 или точное).
  Освободившееся время сразу открывается онлайн; наехать на следующего клиента нельзя — приложение подскажет, кто следующий.
  То же может сделать сам мастер в своём кабинете («Закончу раньше / задержусь»); в журнале такая запись в золотой рамке с ⏱,
  журнал обновляется сам раз в минуту.
- **Push-уведомления** (без регистрации): после записи кнопка «Получать напоминания». Приходят: подтверждение записи, утром в день визита
  с кнопкой «Подтвердить» (с 08:00), за час до начала, при передаче другому мастеру и при отмене. Страница записи клиента `/vesna/v/<id>`.
  Напоминания рассылает `/api/cron/notify` — по расписанию Vercel (утро), из открытого журнала каждые 5 минут и/или внешним будильником.
  Ключи создаются сами и хранятся в базе. iPhone: только iOS 16.4+ и приложение добавлено на экран «Домой».
- **Рассылки** (журнал → «Уведомления»): важное о работе салона или поздравления/акции; кому — записанным на день, всем, женщинам,
  мужчинам, клиентам мастера; шаблоны; от поздравлений и акций можно отписаться.
- **Главная салона** (`/vesna`): логотип, мастера с фото, адрес, WhatsApp. Ставится на телефон как приложение (PWA).

## Технологии

- Next.js 15 (App Router, TypeScript) — веб-приложение для клиентов и сотрудников.
- PostgreSQL + Drizzle ORM.
- Vitest — тесты расчёта свободного времени и цен (`src/lib/engine.test.ts`).

## Запуск

```bash
cp .env.example .env          # укажите DATABASE_URL и ADMIN_PIN
npm install
npm run db:migrate            # создать таблицы
npm run db:seed -- --demo     # данные «Весны» (+ демо-записи на завтра)
npm run dev                   # http://localhost:3000/vesna
npm test                      # тесты
```

## Структура

| Путь | Что там |
| --- | --- |
| `src/db/schema.ts` | Схема данных: салон, сотрудники и роли, графики, категории/услуги/цены, клиенты и семьи, записи |
| `src/db/seed.ts` | Прайс, мастера и графики «Весны» |
| `src/lib/schedule.ts` | Рабочие часы мастера на день (по дням недели или циклом, с исключениями) |
| `src/lib/slots.ts` | Свободные окна для записи |
| `src/lib/pricing.ts` | Цена и длительность записи |
| `src/server/salon.ts` | Каталог, свободное время, создание записи, журнал |
| `src/app/[salon]/…` | Экраны клиента и журнал администратора |

## Дальше (этап 2)

Вход клиентов по коду в WhatsApp · кабинет клиента с баллами и QR · онлайн-оплата (ELQR, карты, Apple/Google Pay) · кабинет владельца: расходы, прибыль · сборка для App Store и Google Play.

**Уведомления (push, если приложение установлено, иначе WhatsApp):**
- три сообщения по записи: при записи, утром в день визита с кнопкой «Подтвердить», за час до начала;
- **рассылка от салона**: хозяйка или администратор пишет сообщение («нет электричества, сегодня не работаем») и выбирает,
  кому отправить — всем клиентам, только записанным на сегодня / на выбранные дни, или клиентам одного мастера;
  вместе с рассылкой можно закрыть салон на день: онлайн-запись закрывается, записи попадают в «Нужно решить»;
- клиенту при переносе / передаче другому мастеру / отмене записи.
- **поздравления и акции**: праздники всем клиентам, 8 Марта — женщинам, день рождения клиента + 100 подарочных баллов (настройка салона);
  отбор по полу, по мастеру или услугам, по давности последнего визита. Для этого клиенту нужны пол и дата рождения
  (необязательные поля в кабинете клиента; пол можно предложить по залу, куда клиент записывается). Клиент может отписаться от
  поздравлений и акций; сообщения о его записях приходят всегда. Push бесплатный; рекламные сообщения в WhatsApp платные — по возможности слать push.

**Журнал:** обычная отмена и перенос записи · «клиент не пришёл» · поиск клиента по телефону.
