# Передача работы (для нового чата с Claude)

Состояние на 26.10.2026. Код: https://github.com/Ajokendo/Vesna_App (ветка main).
Сайт: https://vesna-app.vercel.app/vesna — Vercel (аккаунт Ajokendo), база Neon (подключена в Vercel → Storage).
Каждый push в main публикуется сам; миграции (`drizzle/`) применяются при сборке (`vercel-build`).

## Что есть
Онлайн-запись · журнал администратора (`/vesna/admin`, PIN = переменная ADMIN_PIN в Vercel) · касса с баллами (5% с денежной части,
доля мастера 50% с денежной части, хозяйка Сурмакан без комиссии) · кабинет мастера (`/vesna/master`, PIN выдаётся в журнале
«Мастера и PIN») · выдержка краски · «не выйдет / выйдет в выходной» + блок «Нужно решить» · время окончания (админ и мастер) ·
отмена записи · push-уведомления (при записи, утром с «Подтвердить», за час, перенос/отмена) и рассылки («Уведомления») ·
опоздания: «Пришёл», через 5 мин «позвонить», через 15 мин «Не пришёл» (время освобождается), список «Не пришли и отменённые»,
клиент сам может нажать «Опоздаю на 10/20 мин» или «Не смогу прийти» на странице записи.
Подробности — README.md. Инструкция для салона — Claude Docs (документ «Весна — как пользоваться приложением»), экспорт в PDF.

## Открытые вопросы к салону
Материалы (краска) — делить 50/50 или целиком салону · округление баллов вниз · длительности услуг и выдержки краски ·
WhatsApp Business API (оформляет хозяйка) · напоминания «за час» при закрытом журнале — внешний будильник (cron-job.org → /api/cron/notify).
